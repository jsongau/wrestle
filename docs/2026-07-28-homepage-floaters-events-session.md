## Traps discovered
- **Concurrent Cowork sessions on the same `main` collide.** Observed other-session commits this
  session: b30204e (rankings rebuild — swept my homepage CSS into it) and d653a5b (footer FT3).
  Each caused a stale `.git/index.lock`. CLAUDE.md itself warns "Two agents on one main WILL collide."
  Deploy ritual that worked: `rm -f .git/index.lock` -> `git add -u` -> unstage the 3 other-session
  files -> commit -> verify with `git show --stat HEAD` -> push.
- **Always exclude from my commits:** CHANGELOG.md, CLAUDE.md, and **wrestlers/triple-h/index.html**
  (it references untracked css/profile.css + js/profile.js from a parallel triple-h session; committing
  it would 404 those assets live).
- The corner floaters are **JS-generated by js/home-engage.js**, not static HTML — grep for `.f2-card`
  in index.html returns 0. Redesigning them = editing the JS builder.
- `.wl-totop` computes its bottom from the hero height, which is why it overlapped the Surprise Me disc.
