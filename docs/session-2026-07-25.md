## Architecture Decisions

### Python generator pattern (canonical)
All batches use `build_wrestlers_Xa.py` / `build_wrestlers_Xb.py` scripts with the canonical `build_page()` function established in Batch 3b. Key rules:
- **No backslashes inside f-string `{...}` expressions** (Python 3.11 restriction) — all conditional blocks pre-computed before `return f"""..."""`
- Pre-computed blocks: `champ_block`, `persona_block`, `timeline_block`, `faq_block`, `faq_ld_block`, `retired_html`
- `sig_html` built via string concatenation before the return f-string
- `faq_items_ld` uses `repr()` — safe because it's outside the return f-string

### Gold-standard template sections
Every page has: SEO meta + JSON-LD (Person, BreadcrumbList, optional FAQPage), athlete-hero, wl-strip sparkline, content-grid (bio-col + stats-col), method-bars, championships panel, personas grid, career timeline, FAQ block, sig-matches section, filterable match record table.

## Traps Discovered

- **Python syntax: `pct">12`** — a typo in Batch 6a used `>` instead of `:` inside a dict literal. Always run `python3 build_wrestlers_X.py 2>&1` immediately and check for SyntaxError before committing.
- **`},` vs `),`** — still a risk in row() calls. Copy-paste can introduce closing `}` (dict brace) instead of `)` (function paren). The auto-fixer script from earlier sessions handles this if needed.
